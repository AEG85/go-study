	5. Переменные окружения 

дз1

— Откройте терминал (поздравляю, вы создали окружение уровня сеанса)  
— Создайте в рамках этого терминала переменную окружения, пусть она называется «my_age», а её значением будет ваш возраст  
— Попробуйте получить значение этой переменной окружения в том терминале, в рамках которого вы её создали  
— Попробуйте получить значение этой переменной окружения в другом терминале  
— При попытке получить значение переменной окружения в различных терминалах (в различных сеансах) объясните себе: 
почему в каких-то случаях получается получить значение переменной окружения, 
а в других случаях этой переменной вообще не существует?

дз2

— Напишите программу, получающую значение переменной окружения «my_age».  
— Если «my_age» задана, то выводится её значение. Если «my_age» не задана, то выводится информация об этом.  
— В одном терминале задайте переменную окружения «my_age», запустите из этого терминала написанную программу.  
— Создайте соседний терминал, запустите написанную программу из соседнего терминала.  
— Меняется ли как-то поведение программы в зависимости от того, из какого терминала вы её запускаете? Почему?
