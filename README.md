6. Makefile

дз2

— Напишите на Golang программу, которая читает переменную окружения «OUTPUT_COUNT», преобразует её в целое число, обрабатывая возможные ошибки, а потом в цикле OUTPUT_COUNT раз выводит на экран «Работа цикла: i», где i — номер итерации цикла.  
— Опишите Makefile-таргет, который:  
1. Задаёт переменную окружения OUTPUT_COUNT  
2. Запускает написанную на Golang программу  
— Протестируйте созданную функциональность  

Примеры входных и выходных данных:  

case-1  
—> OUTPUT_COUNT=3  

<-- Вывод программы:  
$ Работа цикла: 1  
$ Работа цикла: 2  
$ Работа цикла: 3  

case-2  
—> OUTPUT_COUNT=5  

<-- Вывод программы:  
$ Работа цикла: 1  
$ Работа цикла: 2  
$ Работа цикла: 3  
$ Работа цикла: 4  
$ Работа цикла: 5
case-3  
—> OUTPUT_COUNT=hello  

<-- Вывод программы:  
$ Ошибка преобразования OUTPUT_COUNT в целое число  

case-4  
—> OUTPUT_COUNT не задана  

<-- Вывод программы:  
$ Переменная окружения OUTPUT_COUNT должна быть задана
