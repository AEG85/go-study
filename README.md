— Для этого задания за основу необходимо взять файлы миграций из предыдущих заданий.  
— У нас в магазине для каждого товара вводится дополнительный параметр: оценка качества. 
Этот параметр не обязателен, ибо не все продукты в принципе проходили оценку качества, но если уж проходили, 
то в этом случае товар может быть либо качественным, либо нет. То есть информация о том, качественный ли товар, может отсутствовать, но если она присутствует, то может принимать только два значения, обозначающие "да, качественный" либо "нет, некачественный".  
— Необходимо при помощи миграций создать 3-ю версию схемы данных, в которой добавляется столбец "качественный товар" в таблицу products.  
— Нужно протестировать up и down файлы 3-й версии схемы данных.

Команда для запуска миграций
migrate -path migrations -database "postgres://postgres:1985@localhost:5432/postgres?sslmode=disable" up
