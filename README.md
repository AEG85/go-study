9. Логгирование 

— Опишите на Golang программу, которая создаёт https://github.com/uber-go/zap логгер, пишущий в консоль и в файл (аналогично логгеру из видео-урока)
— Создайте HTTP сервер на 2 эндпоинтах:

POST /strings, который просто из входящего тела HTTP запроса читает строку, и кладёт эту строку в слайс внутри программы
GET /strings, который в HTTP ответе возвращает в JSON-виде слайс сохранённых ранее строк
— Все входящие и исходящие запросы должны логгироваться: когда пришёл запрос (time.Now), на какой эндпоинт пришёл запрос, 
какой метод у входящего запроса, сколько строк в слайсе оказалось после добавления новой строки POST /strings, 
сколько времени заняло выполнение HTTP эндпоинта, какой статус-код был отправлен в HTTP ответе, время отправки HTTP ответа (time.Now)
— Запустить написанную программу, отправить в неё несколько HTTP запросов, проверить корректность логгирования работы программы
