4. Миграции

дз2

— Для этого задания за основу необходимо взять схему данных из первого задания.  
— Пользователи жалуются, что покупают просроченные продукты. Нам необходимо добавить в таблицу products столбец, 
представляющий дату окончания срока годности продукта.  
— Для добавления столбца "срок годности" необходимо через библиотеку migrate создать новые файлы миграций, 
описать добавление столбца "срок годности" в таблицу products в файле up, описать удаление столбца "срок годности" из таблицы products в файле down.  
— При помощи библиотеки migrate переключиться сначала на 1-ю версию схемы данных, проверить как выглядит схема данных в pgAdmin. 
После переключиться на 2-ю версию схемы данных, убедиться, что столбец "срок годности" действительно добавляется к таблице products.  
— При помощи библиотеки migrate откатиться со второй версии схемы данных на первую, чтобы убедиться, 
что файл down второй версии миграций работает исправно. Проверить схему данных в pgAdmin, убедиться, 
что столбец "срок годности" удаляется из таблицы products.

Команда для запуска миграций
migrate -path migrations -database "postgres://postgres:1985@localhost:5432/postgres?sslmode=disable" up
