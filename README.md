Задание 2

— Опишите простую программу на Golang, которая в цикле 5 раз выводит на экран "Hello from Docker!"
— В конце каждой итерации цикла необходимо останавливать выполнение программы на одну секунду
— Запустите эту программу локально через go run main.go, проверьте корректность её работы
— Опишите Dockerfile, который на основе базового Docker-образа с golang соберёт Docker-образ с вашим приложением, выводящим 5 раз на экран "Hello from Docker!"
— Соберите при помощи этого Dockerfile'a ваш Docker-образ
— Запустите из созданного Docker-образа Docker-контейнер, посмотрите на работу вашего приложения изнутри Docker-контейнера
