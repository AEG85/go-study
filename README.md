Docker
Задание 5

— Возьмите за основу проект из предыдущего задания
— Теперь необходимо описать docker-compose.yaml файл, который позволит удобно запускать внутри Docker-контейнера как наше HTTP приложение, 
так и базу данных PostgreSQL. Да не просто запускать, а ещё и автоматически создавать эти контейнеры в одной Docker-сети, чтобы у HTTP приложения, 
запущенного внутри Docker-контейнера, был доступ к PostgreSQL, запущенной внутри Docker-контейнера.
— Изнутри Docker-контейнеров на локальную машину должны быть пророщены два порта:

1. Порт, который ваше HTTP приложение использует для обработки запросов
2. 5432 порт, используемый для подключения к PostgreSQL из pgAdmin (для мониторинга состояния PostgreSQL и хранимых в ней данных)
— Вынесите под отдельные Makefile-таргеты запуск через docker compose как HTTP приложения (make run-http-app) так и PostgreSQL (make postgres-up)
— Запустите и протестируйте описанную систему через отправку HTTP запросов на пророшенный HTTP порт. Подключитесь к PostgreSQL 
через пророшенный 5432 порт, чтобы следить за корректностью хранимых данных.
