— Необходимо на Golang написать функцию:
ListPages(int N), которая в своих аргументах принимает целое число N, после чего, используя механизм пагинации, достаёт из таблицы books страницы с 
записями одну за одной, каждая страница (кроме последней) должна иметь размер N. Записи каждой полученной страницы должны выводиться на экран с 
соответствующим номером страницы.

Например, если в таблице books было всего 8 книг, а N = 3, то вывод программы после вызова функции ListPages должен выглядеть примерно следующим образом:

console
Страница 1: [BookModel1, BookModel2, BookModel3]
Страница 2: [BookModel4, BookModel5, BookModel6]
Страница 3: [BookModel7, BookModel8]
