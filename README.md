— Для дальнейшей работы с данными в рамках созданной в предыдущем задании SQL таблицы, создайте в коде структуру-модель книги, 
которая бы описывала хранимые в таблице books сущности.  
— Попробуйте все базовые операции над данными в таблице books через SQL запросы, отправляемые через pgx подключение к базе данных:  
1. Опишите на Golang функцию, которая принимает в аргументах структуру-модель книги и при помощи SQL запроса добавляет эту книгу в таблицу books. 
Вызовите эту функцию в вашем коде, запустите программу, посмотрите через pgAdmin что действительно заданная книга создалась в базе данных. 
Поменяйте значения полей передаваемой в функцию модели, после перезапустите вашу программу. Через pgAdmin проверьте, 
что в таблице books появилась вторая запись, представляющая вторую сохранённую на книжной полке книгу. 
Проделайте эти операции несколько раз на ваше усмотрение, чтобы в таблицу books добавить 3–5 различных книг.  
2. Опишите на Golang функцию, которая вычитывает все записи из таблицы books и возвращает слайс структур-моделей книги, 
представляющий набор строк в таблице. Полученный из функции слайс выведите на экран при помощи библиотеки https://github.com/k0kubun/pp. 
Запустите вашу программу, убедитесь, что выведенные на экран модели книг полностью соответствуют книгам, 
хранимым в базе данных в таблице books (чтобы были представлены все книги, чтобы значения полей этих книг были теми же, что и в базе данных).
3. Опишите на Golang функцию, которая принимает в аргументах модель книги, находит в базе данных в таблице books книгу с ID'шником, 
как у переданной модели, 
и этой книге в базе данных обновляет все поля на те, что были у переданной модели. Вызовите эту функцию в вашем коде, запустите программу, 
проверьте через pgAdmin или через написанную в предыдущем пункте функцию, что уже существующая запись в таблице books действительно была обновлена 
(не вставлена новая запись, а именно обновлена уже существующая).  
4. Опишите на Golang функцию, которая принимает слайс ID'шников, и удаляет все записи в базе данных в таблице books с соответствующими ID'шниками. 
Вызовите написанную функцию, запустите программу, убедитесь, что действительно все записи с переданными ID'шниками удалены из таблицы.
