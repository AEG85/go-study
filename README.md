Задание 3

- Напишите на GO программу, которая представляет из себя HTTP-севрер, обрабатывающий пользовательские запросы
- По смысловой нагрузке программа представляет из себя кадровый учет работников вашей компании
- Каждый работкик в компании имеет: уникальный идентификатор ID, ФИО(FullName), Должность(Position)
- Программа позволяет через HTTP запросы:
1. POST /employees - Создать нового сотрудника в кадровом учете
2. GET /employees - Получить список всех работников из кадрового учета
3. DELETE /employees - Удалить какого-то работника
- Для простоты, самих работников программа сохраняет внутри переменной, в данный момент не нужно подключать базу данных
- Запустите эту программу локлально через go run main.go, проверте корректность ее работы
- Опишите Dockerfile, который на основе базового Docker-образа с golang соберет Docker-образ с вашим HTTP-приложением для ведения кадрового учета
- Соберите при помощи этого Dockerfile ваш Docker-образ
- Запустите из созданного Docker-обзраза Docerk-контейнер. Прпробуйте отправить какие-нибудь HTTP зарпосы в ваше приложение, запущенное внутри Docker-контейнера. Возникнут ли какие-нубудь трудности?
- Отсанвоите работающий конейнер с вашим HTTP приложением 
- Снова запустите из созданного в предыдущих пунктах Docker-образа Docker-контейнер с вашим HTTP-приложением, но на этот раз пробросьте сетевой порт, на котором вы запустили HTTP сервер внутри вашего приложения, изнутри Docker-контейнера на локальную машину. Эту длинную команду по запуску Docker-контейнера с пробросом портов вынесите под отлельный Makefile-таргет run-http-app чтобы каждый раз не писать многобукв.
- Попробуйте снова отправить какие-нибудь HTTP запросы в ваше приложение, запущенное внутри Docker-контейнера. Доходят ли HTTP запросы в приложение, запущенное внутри контейнера? Протестируйте работу вашего HTTP приложения "Ведение кадровго учета" внутри Docker-контейнера.
