дз1

Условие первого домашнего задания по теме «Makefile»

— Скачайте и установите Makefile на вашу машину
— Проверьте, что Makefile действительно установлен через команду

make --version

— Опишите самый простой Makefile-таргет, который при помощи shell-команды `echo` будет выводить в консоль «Привет, Makefile!». Назовите его `hello`
— Протестируйте описанный Makefile-таргет, написав в терминале

make hello
