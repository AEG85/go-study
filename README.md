4. Миграции

дз1

— Установите себе на компьютер библиотеку https://github.com/golang-migrate/migrate
— Создайте при помощи этой библиотеки первые файлы миграций, описывающие первую версию схемы данных (up/down). 
Схема данных должна представлять собой таблицу, описывающую продуктовый ряд. У каждого продукта должны быть название и цена 
(обязательные столбцы), таблица с продуктами называется products.
— Примените миграции up. Проверьте, что в базе данных действительно создалась таблица products с описанными полями.
— Примените миграции down. Проверьте, что в базе данных действительно удалилась таблица products.
Команда для миграции
migrate -path migrations -database "postgres://postgres:1985@localhost:5432/postgres?sslmode=disable" up
