— Создайте от мейн ветки вашего локального репозитория ветку feature/postgres, переключитесь на эту новую ветку  
— Установите библиотеку https://github.com/jackc/pgx в ваш проект  
— Создайте через pgx подключение к базе данных PostgreSQL, проверьте созданное подключение через метод Ping() структуры подключения  
— Если подключение установилось успешно, попробуйте в строке подключения задать заведомо неверные параметры, 
чтобы удостовериться в том, что при неверных параметрах подключение не устанавливается и вы видите соответствующую ошибку  
— Добавьте изменения в коммит, сделайте коммит, запушьте ветку feature/postgres на удалённый репозиторий, 
создайте пулл-реквест в мастер ветку, проведите самому себе код-ревью, но пока не мёрджите feature/postgres в мастер.
